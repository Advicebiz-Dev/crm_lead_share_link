# CRM Lead Share Link

Odoo 19 module that adds a **Partilhar** action to CRM Leads and Opportunities.

Version 19.0.1.1.0 changes the popup to follow the visual structure of the native Project Task sharing dialog:

- Hiperligação with copy-to-clipboard icon
- Destinatários
- Nota
- Enviar
- Descartar

The generated URL is an internal Odoo backend link and does not bypass CRM access rights.

To upgrade an existing installation, replace the module folder, restart Odoo, and upgrade `crm_lead_share_link`.
